# 东财DUFE数字党校党课不暂停播放

一个只做一件事的浏览器扩展：让 `szdx.dufe.edu.cn`（数字党校培训平台）的课程视频在切换窗口或标签页时继续播放，并在一节播完后自动处理平台的评价与提示弹窗，让下一节接着播。

- 版本：1.3.0（Manifest V3）
- 适用：Chromium 内核浏览器，Edge / Chrome 111 及以上
- 作用域：仅 `szdx.dufe.edu.cn` 的 `/videodetails/` 视频播放页

> **使用提醒**：建议把播放页窗口一直保留在桌面上，可以放心用其它窗口盖住它去做别的事，遮盖不影响播放；但**尽量不要最小化**。最小化后浏览器的后台节流更激进，可能出现播放异常、无法正常播放，甚至视频被跳过的情况。详见下方常见问题。

---

## 一、有什么用

平台播放页会在窗口或标签页失去焦点时自动暂停视频，同时清掉每 20 秒上报一次学习时长的计时器。也就是说，边看边记笔记、查资料、切到别的窗口，画面和学时记录都会一起停。

视频播到结尾后，平台还会依次弹出三个对话框，每一个都要手点才能继续。其中「确定」之后虽然由平台自己加载下一节，但新一节开始前又有一个「需要完整观看一遍视频」的提示挡着，播放停在 0:00 —— 这才是"播完就不往下走"的真正拦路点。

本扩展解决的就是这两处中断：

1. 失焦不再暂停，切出去做别的事也不影响播放和学时上报。
2. 播完自动依次点掉三个弹窗，形成连续播放，不用守在屏幕前。

## 二、原理（简要）

扩展静态声明 `content_scripts`，在 `document_start` 以 `world: "MAIN"` 注入**页面主世界**。这一点很关键：MV3 的 content script 默认跑在隔离世界，那里改写 `JSON.parse` / `addEventListener` 对页面自己的代码完全无效。

**失焦暂停的四层处理**

1. 钩 `JSON.parse`，把 `/system/getSetting` 返回的 `data.video.rdLostPauseTime` 置为 `0`。这是平台自己的开关，播放页回调只在它等于 `1` 时才调用 `video.pause()`。
2. 播放页不再注册 `visibilitychange` / `blur` 两个自动暂停监听。
3. 播放页伪装成始终可见：`document.hidden = false`、`visibilityState = 'visible'`、`hasFocus() = true`。
4. 兜底看门狗：在 `document` 捕获阶段监听 `pause` 事件，仅当用保存的原生 getter 判断出**页面确实失焦**、且 video 未结束时，才自动 `play()`。前台手动暂停、以及平台「长时间未操作」提醒弹窗都不干预。

**为什么不能禁用 JavaScript**：站点的 m3u8 分片由 `hls.js`（`maxBufferLength: 15`）通过 JS 拉取。禁掉 JS 之后后续分片不再请求，只能播完已缓冲的一小段，这正是"缓存半分钟、播半分钟"的原因。本扩展只摘掉暂停监听，加载链一行不动。

**播完弹窗的自动处理**

`MutationObserver`（childList + attributes）与 1.2 秒低频轮询双驱动，后台标签被节流也能响应。规则按「可见弹窗容器 + 正文特征 + 按钮文字」三重限定，避免误点网络异常提示或定时提醒：

| 顺序 | 弹窗 | 判定文本 | 点击 |
| --- | --- | --- | --- |
| 1 | `课程评价` | 课程评价 / 请为本课程打分 | 跳过 |
| 2 | `提示` | 该视频已播放完毕 | 确定 |
| 3 | `提示` | 完整观看一遍视频 / 获得本课学时 / 视频可以拖动播放 | 我知道了 |

点「确定」后，平台自身的 `videoMsgChange { type: 2, val: "end" }` 会把本节标记为 100% 并请求下一节；点完第三个弹窗后平台自动起播。扩展不主动点目录、不伪造上报，只在必要时做一次保守起播检查。

## 三、能达到什么效果

**能做到**

- 切窗口 / 切标签时，视频按当前倍速继续播放（窗口留在桌面上、被其它窗口盖住也不受影响）。
- 失焦期间每 20 秒一次的 `/lesson/setResourceTime` 上报继续走。
- 播完自动「跳过 → 确定 → 我知道了」，下一节自动开始，全程无需人工干预。
- 右下角常驻绿色角标与扩展弹窗里的计数，可随时自查是否生效。
- 考试页面的切屏检测完全不受影响。

**不做、也做不到**

- 不改播放速度、不跳进度、不拖拽进度条（站点 `ontimeupdate` 有 ±4 秒防拖拽回退）。
- 不自动答题、不自动填写课程评价、不伪造或加速任何学习记录与计时上报。
- 不主动点击目录里的下一节 —— 连播是平台自身的逻辑。
- 不处理平台另一套 `rdPauseTime`「视频已暂停，点击确定继续学习」定时提醒。
- 不收集、不上传任何数据。

## 四、安装

1. **下载解压**：从本仓库的 Releases 页面下载 `szdx-keep-playing-extension.zip`，完整解压后得到一个包含 `manifest.json` 的扩展文件夹（也可以直接 `git clone` 本仓库，仓库根目录就是这个文件夹）。请保留整个文件夹，不要只拷其中某几个文件。
2. **打开扩展管理页并开启开发者模式**：在浏览器地址栏输入 `edge://extensions`（Chrome 用 `chrome://extensions`）并回车，然后打开页面**左下角**的「开发人员模式」开关。
3. **加载扩展**：点击页面左上角的「加载解压缩的扩展」，在弹出的目录选择框里**选中第 1 步解压出来的那个文件夹本身**（不是文件夹里面的文件），确认后扩展会出现在扩展列表里。
4. **刷新播放页确认生效**：登录平台，打开任意课程视频页，按 `F5` 刷新一次。页面**右下角出现常驻的绿色角标**即为安装成功；点击工具栏上的扩展图标，还可以查看拦截、续播、跳过、完成、知晓等计数。

## 五、搭配建议

如果想进一步缩短观看时间，可以搭配 [计时器掌控者](https://timer.palerock.cn/) 这类倍速工具使用，具体用法请参考该工具自己的说明。本扩展本身不修改播放速度。

## 六、权限与隐私

| 权限 | 用途 |
| --- | --- |
| `scripting` | 仅用于弹窗读取注入状态、切换开关、以及「立即注入到当前页」 |
| `*://szdx.dufe.edu.cn/*` | 仅在该站注入随包附带的本地脚本 |

全部代码随包附带，无远程代码、无 `fetch` / `XMLHttpRequest`、无第三方 SDK、无后台常驻服务。设置只写入站点同源 `localStorage`（两个开关）。不读取账号、Cookie 或表单内容，不上传任何数据。

## 七、常见问题

**播放窗口应该怎么放，能不能最小化**：建议让播放页窗口一直停留在桌面上（主页），**不要最小化**。被其它窗口覆盖完全没问题，本扩展会让它继续播放，你可以照常写文档、查资料、聊消息，切走焦点也不会暂停。但不建议最小化：最小化会让浏览器对该页面采取更激进的后台节流，可能影响 m3u8 分片加载、播完弹窗的自动处理和每 20 秒一次的学时上报的时序，表现为画面卡住、视频无法正常播放，严重时平台可能把这一段判定为「跳过视频」，本节学时没有记上。如果发现进度异常，把窗口还原（保持非最小化）并刷新播放页即可；完成状态一律以平台服务端记录为准。

**浏览器版本有要求吗**：需要 Edge / Chrome 111 及以上，因为 `world: "MAIN"` 主世界注入从该版本开始支持。

**为什么安装后一定要刷新一次**：注入脚本声明在 `document_start` 运行，只对「页面加载时」生效；安装扩展前就已经打开的播放页不会自动补注入，所以必须按一次 F5。

**更新扩展后怎么让新版生效，会不会丢播放进度**：在扩展管理页点该扩展的「重新加载」，回到播放页**不必刷新**，点扩展图标里的「立即注入到当前页（不刷新）」，新版脚本会立刻进入主世界，播放进度不丢。想要干净重载也可以点「刷新当前页面并生效」。

**压缩包只有一个吗，里面是什么结构**：是的，只有 `szdx-keep-playing-extension.zip` 一个，解压后外层是一个同名文件夹，直接拿这个文件夹去加载即可。本项目不提供商店上传包。

**扩展弹窗里那些开关是干什么的**：「自动处理播完弹窗」默认开启，关掉后就只保留失焦不暂停、播完不再自动接下一节；「临时停用此功能」可整体停用。切换后刷新或重新注入生效。

**右下角角标没出现**：多半是扩展刚重新加载、旧页面还没补注入，点弹窗里的「立即注入到当前页」或按 F5 刷新即可。

**切走窗口还是停**：先确认角标在，再看弹窗的「续播」计数有没有涨。若计数在涨但画面卡住，多半是后台标签节流让 hls.js 的 15 秒缓冲耗尽，可给浏览器快捷方式追加 `--disable-background-timer-throttling --disable-backgrounding-occluded-windows --disable-renderer-backgrounding` 并重启浏览器。

**播完的弹窗没被自动点掉**：确认弹窗里「自动处理播完弹窗」是开、状态显示「已生效 v1.3」、当前路径是 `/videodetails/`。1.2.0 及更早版本没有第三个「我知道了」弹窗的规则。

**禁用 JavaScript 能解决失焦暂停吗**：不能，m3u8 分片全靠 JS 拉取，禁掉后只能播完已缓冲的一小段。

**项目里有哪些文件**：`manifest.json`（扩展声明）、`inject.js`（主世界脚本）、`popup.html` / `popup.js`（弹窗界面与状态）、`icons/`（16 / 48 / 128 图标）、`README.md`（本文档）、`.gitignore`。
